# Architecture decision records

Short, dated records of decisions that are expensive to reverse. Each one states
the context, the decision, the consequences, and what was rejected.

| ADR | Decision | Status |
| --- | --- | --- |
| [0001](0001-verification-first.md) | Verification-first incident response | accepted |
| [0002](0002-policy-as-code.md) | Policy as code, outside the model | accepted |
| [0003](0003-provider-agnostic-agents.md) | Provider-agnostic agent roles | accepted |
| [0004](0004-temporal-optional.md) | Temporal is optional, not required | accepted |
| [0005](0005-cornershop-evals.md) | CornerShop as the evaluation environment | accepted |

New ADRs are numbered sequentially, never edited after acceptance except to add a
superseding note. A decision that changes gets a new ADR that supersedes the old
one.
